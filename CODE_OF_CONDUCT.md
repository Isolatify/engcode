# Code of Conduct

## Our standard

EngCode exists to make programming reachable for beginners. That shapes how we treat each other here:

- Be patient with beginners — they are the point of the project, not an interruption to it.
- Use plain English. Jargon excludes; clarity includes.
- Critique code and ideas, never people.
- Assume good faith, especially when someone's question seems basic.

Unacceptable behavior includes harassment, insults, personal attacks, publishing others' private information, or any conduct a reasonable person would find hostile to a newcomer.

## Scope

This applies in the repository (issues, pull requests, discussions), in code comments and commit messages, and anywhere the project represents itself publicly.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, and issues that violate this code, and may temporarily or permanently ban contributors who repeat the behavior. If you see something that breaks this code, open a private report through GitHub's report feature on the relevant item, or contact the repository owner through GitHub.
