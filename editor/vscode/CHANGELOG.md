# Change Log

First release of the rewritten EngCode extension.

- Full syntax highlighting for `.eng` files
- Language server: diagnostics as you type, hover documentation, completion,
  Go to Definition, Find References, Rename Symbol, format document,
  `use "..."` document links, and quick fixes
- Snippets for statements, control flow, apps, styles, and events
- Commands: Run File, Serve App, Explain File, Check File
- Debugger: breakpoints, step over/in/out, call stack, locals and globals,
  variable expansion, debug-console evaluation, and `ask` input
